A fun interactive game where you try to guess a secret number between 1 and 100 with helpful hints along the way.

## Overview

Number Guessing Game challenges you to guess a randomly generated number between 1 and 100. After each guess, the game provides hints like higher or lower, and tracks your attempts to help you improve your best score.

## Features

- Random number generation between 1 and 100
- Hints indicating higher or lower
- Attempt counter for each round
- Best score tracking
- Restart game functionality
- Clean and responsive interface

## How It Works

- User opens the game and sees a question mark.
- User enters a guess between 1 and 100.
- User clicks the Guess button.
- The game provides a hint: higher, lower, or correct.
- User continues guessing until the correct number is found.
- The number of attempts and best score are displayed.
- User can restart the game at any time.
