# BMI Calculator

A clean and interactive tool that calculates your Body Mass Index instantly and tells you which weight category you fall into.

## Overview

BMI Calculator helps you quickly determine your Body Mass Index by entering your weight and height. The app displays your BMI value along with a classification ranging from underweight to obese, making it easy to understand where you stand.

## Features

- Instant BMI calculation from weight and height
- Weight category classification with clear labels
- Color-coded results for easy interpretation
- BMI reference guide showing all category ranges
- Responsive design for mobile and desktop

## How It Works

- User opens the BMI calculator.
- User enters weight in kilograms and height in meters.
- User clicks the Calculate button.
- The application computes the BMI and displays the value.
- The corresponding weight category is shown with a message.
- User can refer to the BMI guide below for all ranges.
