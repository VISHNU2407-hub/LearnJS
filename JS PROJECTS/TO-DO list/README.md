## Overview

To-Do List is a full-featured task manager that lets you add, edit, complete, and delete tasks. It includes a progress bar showing completion status, along with statistics for total tasks, completed tasks, and remaining tasks.

## Features

- Add new tasks with descriptions
- Mark tasks as complete with checkboxes
- Edit existing tasks
- Delete tasks when no longer needed
- Real-time progress bar
- Task statistics (total, completed, remaining)
- Persistent local storage

## How It Works

- User opens the to-do list.
- User types a task in the input field and clicks Add Task.
- The task appears in the list with a checkbox.
- User checks the box to mark a task as complete.
- The progress bar updates in real time.
- Statistics show total, completed, and remaining counts.
- User can edit or delete any task.
