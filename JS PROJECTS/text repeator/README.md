# Text Tools — Repeater, Reverser, Case Converter & Word Counter

A versatile text utility toolkit that lets you repeat, reverse, convert case, and count words in your text.

## Overview

Text Tools combines four useful text utilities in one interface. You can repeat text multiple times, reverse strings, convert between uppercase and lowercase, and count words and characters. Each tool is accessible from the sidebar.

## Features

- Text repeater with configurable repeat count
- Text reverser for reversing strings
- Case converter (uppercase, lowercase, title case)
- Word and character counter
- Copy output to clipboard
- Clean input/output workspace layout

## How It Works

- User opens the text tools application.
- User selects a tool from the sidebar (Repeater, Reverser, Case Converter, or Word Counter).
- User types or pastes text in the input area.
- User configures options like repeat count or case type.
- User clicks the action button to process the text.
- The result appears in the output area, ready to copy.
