## Overview

PassGen lets you generate secure passwords with full control over length and character types. You can include uppercase letters, lowercase letters, numbers, and symbols, and see the password strength indicator to ensure your passwords are robust.

## Features

- Customizable password length (8 to 32 characters)
- Toggle uppercase, lowercase, numbers, and symbols
- Password strength indicator
- One-click copy to clipboard
- Tips for creating strong passwords
- Generate another with one click

## How It Works

- User opens the password generator.
- User adjusts the password length using the slider.
- User selects which character types to include.
- User clicks Generate Password.
- A random password is created and displayed.
- The strength indicator shows weak, medium, or strong.
- User can copy the password with one click.
