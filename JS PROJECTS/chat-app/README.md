## Overview

Convo is a feature-rich chat application where users can select from multiple profiles, send messages, and manage conversations. It includes a sidebar for navigation, a main chat area, and a profile panel with detailed user information.

## Features

- Multiple user profiles to choose from
- Realistic conversation list with unread counts
- Message sending with timestamps
- Search conversations by name
- Filter conversations by all, unread, or pinned
- Settings panel with dark mode toggle
- Responsive design for mobile and desktop

## How It Works

- User opens the app and selects a profile from the login screen.
- User browses conversations in the sidebar.
- User can search or filter conversations.
- User clicks a conversation to open the chat area.
- User types and sends messages in real time.
- User can view profile details and shared media.
- User can adjust settings like dark mode or notifications.
