# Weather App

A modern weather application that provides real-time weather data for any city using the OpenWeatherMap API.

## Overview

Weather App lets you search for any city and get current weather conditions including temperature, humidity, wind speed, and pressure. The app features a clean glassmorphism design with real-time weather icons.

## Features

- Search weather by city name
- Display current temperature, humidity, wind, and pressure
- Weather condition icons
- Feels like temperature indicator
- Error handling for invalid cities
- Loading spinner during data fetch
- Responsive design

## How It Works

- User opens the weather app.
- User types a city name in the search bar.
- User clicks the search button or presses Enter.
- The app fetches weather data from the OpenWeatherMap API.
- Current weather conditions are displayed with icons.
- Temperature, humidity, wind speed, and pressure are shown.
- Users can search for a different city at any time.
