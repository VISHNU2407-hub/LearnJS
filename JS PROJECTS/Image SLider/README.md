## Overview

Image Slider is a lightweight image carousel that displays a series of images with previous and next buttons, navigation dots, and captions. It provides a smooth browsing experience for viewing image collections.

## Features

- Image navigation with previous and next buttons
- Navigation dots for direct slide selection
- Image counter showing current position
- Captions with title and description
- Smooth transitions between slides
- Responsive and accessible design

## How It Works

- User opens the image slider.
- The first image is displayed with its caption.
- User clicks the next or previous button to browse images.
- User can click a navigation dot to jump to a specific slide.
- The counter updates to show the current position.
- Captions update to match the current image.
