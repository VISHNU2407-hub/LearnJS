An interactive Pokédex application that lets you search and explore Pokémon with detailed stats, types, and abilities.

## Overview

Pokédex connects to the PokéAPI to provide comprehensive information about any Pokémon. Simply search by name or ID to see detailed stats, type badges, abilities, and a visual representation of the Pokémon.

## Features

- Search any Pokémon by name or ID
- Display Pokémon image, types, and abilities
- Base stats with visual progress bars
- Height, weight, and base experience display
- Previous, next, and random navigation
- Error handling for invalid searches
- Smooth animations and transitions

## How It Works

- User opens the Pokédex.
- User types a Pokémon name or ID in the search bar.
- User clicks Search or presses Enter.
- The application fetches data from the PokéAPI.
- Pokémon details including image, types, and stats are displayed.
- User can navigate to previous, next, or random Pokémon.
