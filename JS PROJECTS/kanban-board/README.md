# Kanban Board

A visual project management board that helps you organize tasks into columns and track their progress from start to finish.

## Overview

Kanban Board is a task management tool that uses the kanban methodology to help you organize work. Tasks are represented as cards that move across columns representing different stages like To Do, In Progress, and Done.

## Features

- Drag and drop cards between columns
- Create, edit, and delete tasks
- Search and filter tasks
- Sort tasks by priority or due date
- Responsive design for all devices
- Persistent storage of board state

## How It Works

- User opens the kanban board.
- User can create new tasks with titles and descriptions.
- Tasks appear as cards in the appropriate column.
- User drags cards between columns to update their status.
- User can edit task details or delete tasks.
- Board state is saved automatically.
