## Overview

Notes App provides a complete note-taking experience with a sidebar for navigation, a list view for browsing notes, and an editor for writing. It supports search, favorites, and persistent storage so your notes are always saved.

## Features

- Create, edit, and delete notes
- Search notes by title or content
- Mark notes as favorites
- Trash system for deleted notes
- Dark mode toggle
- Persistent local storage
- Clean three-panel layout

## How It Works

- User opens the notes app.
- User can browse all notes, favorites, or trash from the sidebar.
- User clicks the New Note button to create a note.
- User types a title and content in the editor panel.
- Notes are automatically saved to local storage.
- User can search notes or mark them as favorites.
