## Overview

Finwise is a complete personal finance tracker that lets you record transactions, categorize expenses, and view your financial health at a glance. It includes an interactive dashboard with balance overview, progress bars for expense categories, and detailed transaction history.

## Features

- Dashboard with balance, income, and expense summaries
- Add income and expense transactions
- Categorize transactions with custom categories
- Search and filter transaction history
- Expense breakdown with progress bars
- Dark mode support
- CSV data export
- Persistent data storage

## How It Works

- User opens the dashboard and sees the financial overview.
- User adds transactions by selecting type, amount, category, and description.
- Transactions appear in the history list with search and filter options.
- Expense summary shows spending breakdown by category.
- User can edit or delete transactions as needed.
- Settings allow toggling dark mode, changing currency, or exporting data.
