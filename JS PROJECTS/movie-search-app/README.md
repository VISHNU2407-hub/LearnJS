# Movie Search App

A powerful movie discovery tool that lets you search for movies and view detailed information using the OMDb API.

## Overview

Movie Search App connects to the OMDb API to provide comprehensive movie information. Users can search for any movie, browse results in a grid, and click through to view detailed information including ratings, plot, cast, and more.

## Features

- Search movies by title
- Grid view of search results with posters
- Detailed movie view with full information
- IMDb rating, runtime, genre, and plot display
- Awards and box office information
- Responsive design for all devices

## How It Works

- User opens the movie search app.
- User types a movie title in the search bar.
- User clicks search or presses Enter.
- Results appear as a grid of movie cards with posters.
- User clicks a movie card to view full details.
- Detailed information including ratings, plot, and cast is displayed.

## Technologies Used
