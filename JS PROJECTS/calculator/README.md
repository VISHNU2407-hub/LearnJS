## Overview

Calculator is a modern take on the classic calculator app. It supports addition, subtraction, multiplication, division, and modulo operations. The display shows both the expression and the result for a seamless calculation experience.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division, modulo
- Expression preview showing the full calculation
- Clear and delete functionality
- Responsive grid button layout
- Keyboard-friendly interaction

## How It Works

- User opens the calculator.
- User clicks number buttons to enter values.
- User clicks an operator button to select an operation.
- User continues building the expression.
- User clicks equals to see the result.
- User can clear the display or delete the last entry.
