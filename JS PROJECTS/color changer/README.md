# Color Changer

A fun interactive tool that changes the background color with every click and displays the current color code.

## Overview

Color Changer lets you generate random background colors with a single click. Each click produces a new color and displays its hex code, making it a great tool for exploring color combinations.

## Features

- Random color generation on each click
- Displays the current hex color code
- Smooth background color transitions
- Simple and intuitive interface

## How It Works

- User opens the color changer.
- The current color and its hex code are displayed.
- User clicks the Change Color button.
- A random color is generated and applied as the background.
- The hex code updates to match the new color.
