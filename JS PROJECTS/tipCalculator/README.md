# Tip Calculator

A handy tool that calculates tip amounts, total bills, and per-person splits for group dining.

## Overview

Tip Calculator makes it easy to figure out how much to tip at restaurants. Enter your bill amount, select a tip percentage, and optionally split the bill among multiple people. The app shows tip amount, total bill, and per-person cost.

## Features

- Bill amount input
- Pre-set tip percentages (5%, 10%, 15%, 20%, 25%)
- Custom tip percentage option
- Split bill among multiple people
- Tip amount, total, and per-person display
- Reset button to clear all fields

## How It Works

- User opens the tip calculator.
- User enters the bill amount.
- User selects a tip percentage or enters a custom one.
- User optionally sets the number of people to split the bill.
- User clicks Calculate.
- The app displays the tip amount, total bill, and per-person cost.
