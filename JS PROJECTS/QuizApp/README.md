# Quiz App

An interactive quiz application that tests your knowledge with multiple-choice questions and tracks your score in real time.

## Overview

Quiz App presents a series of multiple-choice questions on various topics. Each question has a timer, and you receive immediate feedback on your answers. At the end, you see your final score with correct and incorrect counts.

## Features

- Multiple-choice question format
- Timer countdown for each question
- Immediate correct or incorrect feedback
- Score tracking throughout the quiz
- Final results screen with statistics
- Restart option to play again

## How It Works

- User opens the quiz and starts by clicking Start Quiz.
- A question with four options is displayed with a timer.
- User selects an answer by clicking an option.
- Correct and incorrect answers are highlighted immediately.
- User clicks Next to proceed to the next question.
- After all questions, the final score is displayed.
- User can restart the quiz at any time.
