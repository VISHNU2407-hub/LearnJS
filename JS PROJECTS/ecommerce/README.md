## Overview

ShopWave is a complete e-commerce shopping experience that lets users browse products, view detailed product information, add items to a cart or wishlist, and proceed through a multi-step checkout process. It includes a user profile section for managing orders.

## Features

- Product browsing with grid and list views
- Product detail pages with images and descriptions
- Shopping cart with quantity management
- Wishlist for saving favorite items
- Multi-step checkout process
- Order history and tracking
- User profile management
- Category-based filtering and search

## How It Works

- User opens the store and browses products on the homepage.
- User can search or filter products by category.
- User clicks a product to view details and images.
- User adds items to the cart or wishlist.
- User proceeds to checkout, enters shipping details.
- User reviews the order and completes the purchase.
- User can view order history in the profile section.
