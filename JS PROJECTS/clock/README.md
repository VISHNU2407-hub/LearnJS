# Digital Clock

A beautifully designed digital clock that displays the current time with hours, minutes, and seconds in a clean, readable format.

## Overview

Digital Clock shows the current time in a bold, easy-to-read display. It updates every second and also shows the current date, making it a functional and attractive addition to any workspace.

## Features

- Real-time hours, minutes, and seconds display
- Automatic updating every second
- Current date display
- Clean and minimal design
- Fully responsive layout

## How It Works

- User opens the digital clock.
- The current time is displayed immediately with hours, minutes, and seconds.
- The clock updates automatically every second.
- The current date is shown below the clock.
