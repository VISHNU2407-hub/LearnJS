# GitHub Profile Finder

A sleek tool that lets you search for any GitHub user and view their profile details and repositories in a clean, organized layout.

## Overview

GitHub Profile Finder connects to the GitHub API to fetch and display user profiles. Simply enter a GitHub username to see their avatar, bio, stats, and a list of their repositories with key information like stars, forks, and languages.

## Features

- Search any GitHub user by username
- Display user profile with avatar, bio, and stats
- List user repositories with details
- Recent searches for quick access
- Error handling for invalid usernames
- Responsive design

## How It Works

- User opens the application and enters a GitHub username.
- User clicks the search button or presses Enter.
- The application fetches profile data from the GitHub API.
- User profile information and repositories are displayed.
- User can click on repositories to visit them on GitHub.
- Recent searches are saved for quick access.
