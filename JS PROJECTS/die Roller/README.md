# Dice Roller

A virtual dice rolling simulator that lets you roll a die and track your roll history with a simple click.

## Overview

Dice Roller simulates rolling a standard six-sided die. Each roll generates a random number from 1 to 6, displayed on a realistic dice face. The app also keeps a history of your recent rolls for reference.

## Features

- Random dice roll from 1 to 6
- Visual dice face display
- Roll history tracking (last 5 rolls)
- Smooth rolling animation
- Responsive design

## How It Works

- User opens the dice roller.
- The current dice value is displayed.
- User clicks the Roll Dice button.
- A random number between 1 and 6 is generated.
- The dice face updates with an animation.
- The roll is added to the history list.
