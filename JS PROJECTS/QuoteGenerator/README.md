# Random Quote Generator

An inspiring application that displays random quotes from famous figures and lets you share or copy them with ease.

## Overview

Random Quote Generator presents a new inspiring quote every time you click a button. Each quote includes the author's name, and you can copy the quote to your clipboard or generate a new one for daily inspiration.

## Features

- Random quote generation on each click
- Author attribution with each quote
- Copy quote to clipboard functionality
- Clean and elegant card layout
- Responsive design

## How It Works

- User opens the quote generator.
- A random quote is displayed with the author's name.
- User clicks New Quote to see a different quote.
- User can copy the current quote using the Copy button.
- A new random quote is fetched and displayed.
